# src/utils/

纯展示辅助函数，不访问网络、不读写浏览器存储。

| 文件 | 内容 |
|---|---|
| `format.ts` | 年级中文名称、会话时间格式、用户显示名与头像首字 |
| `settingsForm.ts` | 个人设置的客户端校验与提交字段构造（只提交改动过的字段） |
| `pendingReply.ts` | 切回仍在后台生成的会话时，判断是否补等待气泡及等待起点 |
| `figure.ts` | 图示的纯计算：参数初值、按顺序解析点坐标、观察值、视窗范围与宽高比适配 |
| `figureExpr.ts` | 图形算式的白名单解析与求值（不用 eval）、数值与分数格式化 |
| `waiting.ts` | 等待时的阶段文案（按会话阶段与是否带图分组、随时长推进）、已等时长格式化 |
